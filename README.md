# كن مثقفا — Kun Muthaqqafan

Smart Reading & Personal Library. A privacy-first, offline-capable reading ecosystem: manage your book collection, import PDF/EPUB/TXT from your device, read with progress tracking, take notes, highlight passages, review with spaced repetition, and discover new books via Open Library.

Arabic (RTL) and English. Light, dark and system themes. No account required for core features.

## Status

Batch 1 (this build): design system, 5-tab shell, library CRUD with real SQLite persistence, local-file import registry, Open Library discovery, settings (theme/language/daily goal). Full PDF/EPUB/TXT readers, annotations, AI summaries and review sessions arrive in following batches — no placeholder buttons are shipped as finished features.
